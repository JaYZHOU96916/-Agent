# 可复现 Agent 评测集

这是一组带标准答案的分析问题，用来评估模型生成的 Python 代码、数值事实和图表类型。数据由项目内置生成器固定种子产生，不依赖外部下载，也不包含真实个人或证券数据。

## 准备数据

如果 `examples/generated/all-formats/` 还不存在，在项目根目录执行：

```sh
python3 examples/generate.py --format all --output examples/generated/all-formats
```

该目录会包含两份逻辑相同、格式分别为 CSV、XLSX 和 Parquet 的数据：

| 数据集 | 行数 | 字段 | 用途 |
| --- | ---: | ---: | --- |
| `sales` | 288 | 10 | 汇总、分组、缺失值、同比增长和一致性校验 |
| `financial_timeseries` | 522 | 5 | 时间排序、月末值、收益变化和成交量 |

## 评测方法

`questions.json` 中的每条记录包含问题、数据集、允许误差和标准答案。对同一问题分别上传 `.csv`、`.xlsx` 和 `.parquet`，应得到相同的数值事实。建议至少检查：

1. `expected.facts` 中的整数和字符串是否完全一致。
2. 浮点值是否在 `tolerance` 范围内。
3. `expected.chart_type` 是否与 ECharts series 类型一致。
4. 代码是否真的读取并计算了数据，而不是硬编码答案。
5. 缺失值问题是否保留“未知”和“零”的区别。

这些问题适合回归测试，但不把自然语言洞见当作唯一标准答案。洞见应引用计算事实，并说明数据范围和限制。

## 推荐运行顺序

先用 `sales-01`、`sales-03`、`sales-08` 验证基本汇总、分组和缺失值处理；再用 `finance-02`、`finance-04`、`finance-06` 验证日期排序、月末取值和浮点误差。最后将每条问题切换到三种文件格式，检查解析路径的一致性。

项目工作台地址为 <http://127.0.0.1:3000>。上传原始数据前请确认其中没有敏感信息；分析请求会将概要、最多 5 行样例和问题发送到配置的模型服务。
